# Hope Lishiko - Student Portfolio Website

## About the Website

This is my personal student portfolio website created for the ICT251 Web Technologies practical activity.

The website presents information about me, my hobbies, learning plan, projects, skills, photos, media and contact information.

## JavaScript Features

The website includes the following interactive JavaScript features:

1. Contact form validation and preview
2. Expandable project details
3. Photo gallery viewer
4. Project search and filtering
5. Light/Dark theme switch
6. Study hours calculator
7. Mobile navigation menu

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Testing

The website was tested locally using VS Code Live Server.

I tested:

- Navigation links
- CSS styling
- JavaScript features
- Contact form validation
- Photo gallery
- Video and audio
- Responsive layout
- Mobile navigation
- Light and dark themes

The website was also uploaded to GitHub and will be deployed using Render.
